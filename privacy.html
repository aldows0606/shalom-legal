SHALOM – Privacy Policy

Last updated: October 3, 2026

SHALOM is a private content tool operated by Daniel Santana Peña to manage a single TikTok account. This policy explains what data it handles.

1. Data we access

When the account owner connects TikTok, SHALOM receives an access token and basic account information (such as the account's open ID and display name) through TikTok Login Kit. This is used only to upload drafts to that same account.

2. Data we do not collect

SHALOM does not collect data from other TikTok users, followers or viewers. It does not read comments, messages or contacts, and it does not use cookies or tracking on visitors.

3. How data is stored

Access tokens are stored securely in the operator's private automation environment and are used only to call the TikTok Content Posting API. Generated images are stored temporarily on the operator's server so TikTok can retrieve them, and are deleted within 48 hours.

4. Sharing

Data is not sold or shared with third parties, except the TikTok API itself, which receives the content being uploaded.

5. Deleting data

The account owner can revoke SHALOM's access at any time from TikTok settings (Security and permissions, Apps). Tokens are then deleted from our systems.
